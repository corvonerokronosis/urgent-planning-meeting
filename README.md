# Срочная планёрка

Полноценная небольшая браузерная decision game по ТЗ: один напряжённый рабочий день, 12 решений за прохождение, 15 настроенных событий, четыре ресурса и последствия, которые возвращаются через несколько ситуаций.

## Что есть в версии 1.1

- 12 игровых этапов и три содержательные развилки; повторные прохождения отличаются событиями, репликами и финалом;
- 15 событий в конфигурации, 45 вариантов решений и пять персонажей с разными ролями;
- четыре показателя: `Сроки`, `Бюджет`, `Команда`, `Клиент`;
- немедленные и отложенные эффекты, условные сообщения и недоступные при определённых условиях варианты;
- два режима прозрачности, три испытания и отключаемый таймер в кризисных решениях;
- доверие пяти персонажей, активные сюжетные линии и вариативные микро-события;
- аварийное восстановление или досрочный итог при достижении нуля ресурса;
- шесть итоговых профилей, рассчитанных по ресурсам и ключевым решениям;
- три поворотных решения и фильтруемый разбор с отдельными отложенными эффектами;
- автоматическое локальное восстановление незавершённого прохождения;
- адаптивный desktop/mobile интерфейс и поддержка `prefers-reduced-motion`;
- локальные события аналитики без передачи данных во внешние сервисы.

## Запуск

Требования: Node.js 20+ и pnpm.

```bash
pnpm install
pnpm dev
```

Vite выведет локальный адрес приложения в терминале.

## Production build

```bash
pnpm build
pnpm preview
```

Готовая статическая сборка появится в `dist/` и может быть размещена на обычном web-хостинге без backend.

## Проверки

```bash
pnpm test
pnpm build
```

Тесты проверяют структуру 12-этапного сценария, ветки, четыре шкалы, отношения, условные ответы, отложенные последствия с источниками, кризисы, испытания, микро-варианты, поворотные решения и все шесть финалов.

## Структура

- `src/data/scenario.ts` — события, ветки, решения, эффекты, флаги, реакции и выводы для разбора;
- `src/data/characters.ts` — персонажи, роли и параметры аватаров;
- `src/game/engine.ts` — чистые функции условий, маршрутизации, последствий, шкал и финалов;
- `src/game/useGameController.ts` — состояние прохождения, история решений и localStorage;
- `src/components/` — старт, чат, участники, показатели, решения, последствия и финальный разбор;
- `src/styles/global.css` — визуальная система, состояния, анимации и адаптив;
- `docs/content-model.md` — руководство по изменению и расширению сценария;
- `docs/design/messenger-concept.png` — исходный визуальный концепт.

## Локальная аналитика

Игра не отправляет данные во внешние системы. Для необязательной интеграции она генерирует браузерное событие `urgent-planning:game-event` с типами `start`, `resume`, `choice`, `crisis`, `finish`. Слушатель можно подключить на странице-хосте без изменения движка.

## Данные и ограничения

Backend, авторизация и персональные данные не используются. Незавершённый прогресс хранится только в `localStorage` браузера под версионированным ключом и полностью очищается при новом прохождении.
